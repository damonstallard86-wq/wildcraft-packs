# Wildcraft state packs

Public nature data for the Wildcraft Android app (Kentucky and Indiana are built into the app).

**wildcraft-pack-6states.json**: one offline pack for Ohio, Tennessee, Illinois, West Virginia, Virginia, and Missouri.

What it contains (public nature info only, nothing personal, no radio data):
- Where each card is found, by state (native / invasive / rare), from iNaturalist and GBIF sightings, plus the USDA PLANTS Database for plants.
- 12 extra cards for animals and plants of these states, with openly licensed photos (Wikimedia Commons; credits are inside the file and shown in the app).
- Links to each state's official fishing and license pages. Rules are not copied; check the official page for current regulations.

The app downloads this file over Wi-Fi from:
`https://github.com/damonstallard86-wq/wildcraft-packs/releases/latest/download/wildcraft-pack-6states.json`
